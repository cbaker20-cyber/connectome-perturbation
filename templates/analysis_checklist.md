# Analysis Checklist

Before interpreting any result:

- [ ] Is this exploratory or validated?
- [ ] Are baseline and perturbation trial counts matched?
- [ ] Are zero-spike trials retained?
- [ ] Are output files archived?
- [ ] Are exact neuron sets saved?
- [ ] Does the script use the intended data version/materialization?
- [ ] Are raw p-values and FDR q-values clearly separated?
- [ ] Are non-significant trends labeled as trends?
- [ ] Does the claim overstate the silencing model?
- [ ] Is the result entered in `04_RESULTS_LEDGER.csv`?
- [ ] Is the claim entered or updated in `11_CLAIMS_REGISTER.csv`?
