# Epistemic rules (for humans and for any AI editing this repo)

These rules exist because this project already accumulated documents that
treated one paper, one default parameter, or one web summary as *the* answer.

1. **Do not collapse competing accounts.** If two peer-reviewed (or preprint)
   sources disagree, name both and say what observation would separate them.
   Ranking by citation count or search-engine position is not a method.

2. **Assumptions are labeled as assumptions.** Equal |E| and |I| weights,
   glutamate = inhibitory, basal rate = 0 Hz, and “top_nt is the transmitter”
   are all assumptions in this stack. They may be useful. They are not facts
   about the fly.

3. **Simulation output is not behavior.** Motor ΔHz is a number the LIF
   network produced. Linking it to feeding, grooming, or escape requires a
   separate, cited argument and usually an experiment that this repo does not
   contain.

4. **Do not promote screens.** n=5, uncapped class lesions, and single-map
   polarity groups are hypothesis generators. A claim that will be written
   into a Regeneron report needs stated n, FDR, a null, and at least one
   assumption-sensitivity check (second NT map or I:E ratio).

5. **Do not write the research report.** STS rules: AI may be used in the
   research work and must be disclosed; AI must not draft the Research Report
   or invent citations. This repository may hold methods, code, and numbered
   results. The prose argument is written by the student from those files.

6. **IDs stay strings.** FlyWire root IDs can exceed 2^53. Never float them.

7. **Materialization 630 and 783 are different datasets.** Do not quote a
   count from one next to a result from the other without saying so.
