# Review after the CCR results, 27 September 2026

The defensible result is that one selected 51-cell set produces a larger within-set rate response than three chosen comparison sets across this parameter grid. It also produces a large MN9 decrease without having to lesion MN9 itself. This is useful evidence about a selected perturbation in this model. It does not yet establish that eigenmodes identify independent circuits, or explain the effect beyond connectivity and recruitment.

## Immediate work: inspect existing evidence

They verify the frozen upload, plan structure, six recorded output hashes per trial, spike/rate agreement, actual input-event digests and paired input tapes. ## Analysis once the export returns

First reconcile every paired total against per_seed.csv from the completed collection. For the large-response setting, plot baseline and lesion population traces side by side for every seed, ordered by seed rather than effect size. Compare rates and recruitment with default. A high but valid firing rate is not by itself a numerical error or proof of a dynamical transition. If an invariant fails, report the exact trial and stop interpretation until the cause is identified.

Then reconstruct signed neuron-level changes on the full neuron universe. Reproduce the original mean-vector A and F before adding readouts. Estimate paired contrasts by resampling whole seed rows, using the same resample for mode and comparator and recomputing the signed mean vector before taking absolute values. Retain all nine settings and three comparator contrasts; any intervals are retrospective descriptive intervals. Do not treat 27 shared-data contrasts as 27 independent confirmations.

For full mode versus other-50, compare signed response vectors on the same 51-cell support and on the whole network. Report the norm of their difference and their signed spatial agreement, with undefined normalization handled explicitly for zero vectors. Also compare the joint response with the sum of 51 single-lesion response vectors at default. This tests non-additivity within the model; it does not identify which pairwise interaction or biological mechanism caused it. Do not infer these spatial properties from the MN9 scalar alone.

For each of the 22 zero-rate-effect cells, retain its baseline rate and spike-table equality across all 30 seeds. This separates silent cells, unchanged complete recorded trains, and timing changes with unchanged counts. It still does not establish a role under other inputs.

## Further simulations: decisions before spending compute

If the saved traces pass the checks, the first new simulations should be exact replay of the exceptional cases and ordinary cases under the recorded software and settings. Select them by a written rule: every condition's largest-total seed at weight 1.2/inhibition 0.8 plus its median-total seed, with ties resolved by smallest seed. Record this as a targeted reproducibility diagnostic, not a representative sample. Replay disagreement would require resolving reproducibility before a larger study.

A time-step check would follow only with a validated method for replaying the same physical input event times at 0.1, 0.05 and 0.025 ms. Reusing the same seed while regenerating a different-length Bernoulli tape would confound integration and input changes. Compare output trajectories and effect summaries rather than demanding identical spikes across time steps. The current production runner fixes dt; this extension is not implemented or silently enabled here.

The next hypothesis test should remain narrow: does this frozen candidate show greater response concentration than an explicitly defined, adequately balanced reference ensemble on held-out inputs? Matching is the prerequisite. Fresh input seeds address reuse of input realizations, not the adaptive choice of a favorable structural candidate. A claim across eigencircuits requires a separate, frozen multi-mode design. Neither additional sugar seeds nor a larger parameter grid can substitute for that design.

No arbitrary new rejection threshold has been chosen after seeing these results. Before a confirmatory run, specify the primary contrast, reference-set sampling and exchangeability assumptions, balance criteria, smallest effect of interest, number of reference sets, seed count and multiplicity treatment. If the available network cannot provide balanced controls, change the claim rather than relax matching until it passes. An empirical rank p-value is not justified simply by generating many optimized sets.

## Paper notes

Pospisil et al., The fly connectome reveals a path to the effectome, Nature (2024), DOI 10.1038/s41586-024-07982-0. Their structural modes prioritize populations and activity patterns for dynamical study. This motivates candidate selection here; it does not make deleting a support equivalent to driving an eigenmode. An anatomical mode is also not automatically a local linearization of the driven spiking model. [Published paper](https://api.repository.cam.ac.uk/server/api/core/bitstreams/1b44c48c-2482-4148-b4e1-36c36c2c42a4/content).

Shiu et al., A Drosophila computational brain model reveals sensorimotor processing, Nature (2024), DOI 10.1038/s41586-024-07763-9. The connectome-based spiking model provides the simulation framework. Results here are conditional on that model and its physiological simplifications; simulated MN9 firing is not observed feeding behavior. The recommendation to inspect our unusual traces is our methodological inference, not a conclusion from their paper. [Paper](https://www.nature.com/articles/s41586-024-07763-9).

Austin, Balance diagnostics for comparing the distribution of baseline covariates between treatment groups in propensity-score matched samples, Statistics in Medicine (2009), DOI 10.1002/sim.3697. The relevant lesson is to examine distributions and variances as well as means. This epidemiological work supplies neither a fly-specific balance cutoff nor a valid randomization scheme for optimized neuronal sets. [Paper record](https://pubmed.ncbi.nlm.nih.gov/19757444/).
