# Research Gaps

This file tracks where the project can contribute without pretending existing work does not exist.

## Working Gap

Static graph structure identifies hubs, motifs, and modules. Forward simulation can predict activity flow from defined inputs. The gap this project targets is counterfactual dependency:

> What does a defined sensory-output computation depend on under virtual perturbation, and how does that dependency differ from structural centrality?

## Claims To Compare Against Literature

- Full-brain connectome mapping.
- Network/rich-club analysis.
- Sensory-to-motor simulation.
- Effectome or influence modeling.
- Virtual lesion / in silico perturbation studies.
- Minimum-cut and bottleneck algorithms.

## Project-Specific Novelty Test

A result is interesting only if it survives these questions:

1. Would degree/PageRank have found the same targets?
2. Does the vulnerability signature change by context?
3. Is the result stable under reasonable parameter changes?
4. Does a toy graph with known answer pass first?
5. Is the language limited to model-predicted vulnerability?
