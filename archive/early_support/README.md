# Early support files

These files were part of the initial Shiu/Brian2 integration and early context
work. They are retained as provenance for how the project began, but are not
part of the current experiment entry points. The active pipeline uses
`model.py`, `perturbation/`, `scripts/`, `tools/`, and the explicit input
manifest instead.

`visualize.py` is retained here because it generated the first motor-impact
figure; it is not an active claim-generation tool.

`legacy_smoke_run.py` is the original executable smoke test renamed so automated
test discovery cannot run a full simulation accidentally.
