# Exploratory structural support

These scripts were used during intermediate graph/null analyses and helped
inform later controls, but are not current experiment entry points. The early
null aggregation code predates the corrected empirical p-value implementation;
use the current null runners and statistics code for new results.

The archived AN source-target and signed-motif modules were exploratory controls,
not validated biological results. Their legacy test is retained for inspection
but is intentionally not part of the active test discovery. The surrogate
benchmark used a hand-weighted composite score and is retained only as a record
of an intermediate approach, not as a claim-generating method.
